# 대학알리미 공시 데이터 일괄 다운로드

대학알리미의 공시 DATA 다운로드 목록에서 대표 항목 112개를 구성해 항목당 한 번만 선택합니다. 2026년 자료를 우선 사용하고, 2026년 자료가 없는 항목은 2025년으로 대체합니다. 대학알리미의 최대 10개 제한에 맞춰 자동으로 묶음을 나눠 다운로드합니다.

## 실행

Node.js 18 이상에서 `start.cmd`를 더블클릭하거나 다음 명령을 실행합니다.

```powershell
node server.mjs
```

브라우저에서 `http://localhost:4173`을 엽니다.

`대학알리미_데이터수집기.html`을 더블클릭해 HTML 파일로 열 수도 있습니다. 데이터 조회와 저장 기능을 사용하려면 `start.cmd`로 로컬 서버가 실행 중이어야 합니다.

## 사용 순서

1. 수집할 학교 종류를 하나 이상 선택합니다. 복수 선택과 전체 선택/해제를 지원합니다. 전체 학교를 선택하면 대표 항목 112개로 구성하고, 일부 학교만 선택하면 해당 학교의 제공 항목만 다운로드합니다.
2. 사용자 구분, 다운로드 목적, 상세 내용을 확인합니다.
3. **전체 항목 조회**를 누릅니다.
4. 조회 결과와 2025년 대체 항목 수를 확인합니다.
5. **10개씩 전체 자동 다운로드**를 누릅니다. 학교 종류별로 분리한 뒤 각 ZIP에 최대 10개 항목을 담아, 마지막 항목까지 순서대로 자동 다운로드합니다.

ZIP을 남기지 않으려면 먼저 **저장 폴더 선택**을 누르고 폴더를 지정합니다. 폴더가 지정되면 **선택 폴더에 다운로드** 버튼이 활성화됩니다. 이 버튼을 누르면 앱이 ZIP을 메모리에서만 풀어 내부 파일을 선택한 폴더에 직접 저장합니다. 이 기능은 폴더 접근 API를 지원하는 최신 Chrome 또는 Edge에서 사용할 수 있습니다. 기존 방식이 필요하면 **ZIP으로 받기**를 사용합니다.

## 2단계: 데이터 정제

1. **정제할 원본 폴더 선택**을 눌러 1단계에서 내려받은 XLSX/XLS 파일 폴더를 선택합니다.
2. **정제 시작**을 누릅니다.
3. 원본 폴더 하위의 `정제` 폴더에서 결과를 확인합니다. 결과 파일명은 확장자 앞에 `_정제`가 붙습니다. 예: `원본파일.xlsx` → `원본파일_정제.xlsx`.

정제 과정은 상단 1~3행을 삭제하고, 제2~4캠퍼스 및 지역명이 붙은 동일 대학을 통합합니다. 합계형 수치는 합산하고 비율·평균·평점·1인당 지표는 전체·대상·정원·인원 열을 분모로 찾아 가중 재계산합니다. 고려대학교, 건국대학교, 동국대학교, 연세대학교, 한양대학교와 지침에 지정된 각 분교는 서로 통합하지 않습니다. Excel의 원본 파일 복구 및 계산 엔진을 사용하므로 Microsoft Excel이 설치된 Windows 환경이 필요합니다.

## 3단계: 데이터 대시보드

1. 정제 폴더가 있는 원본 폴더를 선택합니다.
2. 개별 대시보드 또는 전체 대시보드를 선택하고 생성합니다.
3. 원본 폴더 하위 `대시보드` 폴더에서 결과를 확인합니다. 개별 문서는 정제 파일과 같은 이름의 HTML로, 전체 문서는 `통합_대시보드.html`로 저장됩니다.

대시보드에는 핵심 지표 타일, 학교종류·검색 필터, 상위 항목 비교 차트, 숫자 지표 구성 차트와 상세 데이터 표가 포함됩니다.

브라우저가 여러 파일 다운로드 권한을 물으면 허용해야 모든 ZIP 묶음을 저장할 수 있습니다. 대학알리미의 화면/API가 변경되거나 서비스가 점검 중이면 조회·다운로드가 일시적으로 실패할 수 있습니다.

## Railway PostgreSQL

Railway 프로젝트에 PostgreSQL 서비스를 추가한 뒤 앱 서비스의 `DATABASE_URL` 변수에 `${{Postgres.DATABASE_URL}}` 참조를 연결합니다. 다음 배포부터 서버가 `catalog_cache`와 `download_events` 테이블을 자동으로 생성합니다.

- `catalog_cache`: 학교 종류별 공시 항목 목록을 30분간 캐시합니다.
- `download_events`: 다운로드 성공·실패, 항목 수와 요청 구분을 기록합니다.
- `GET /api/health`: PostgreSQL 활성화 및 연결 상태를 반환합니다.

`DATABASE_URL`이 없는 로컬 환경에서는 PostgreSQL 기능만 비활성화되고 기존 다운로드 기능은 그대로 동작합니다.

웹 정제·대시보드 기능은 Railway Bucket의 `AWS_ENDPOINT_URL`, `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_REGION`, `BUCKET` 환경변수를 자동으로 사용합니다. 원본·정제·대시보드 파일은 Bucket에 저장하고 `stored_files` 테이블에는 단계, 파일명, 객체 키와 크기를 기록합니다. HTTPS 환경에서는 Chrome 또는 Edge의 폴더 접근 기능으로 원본 파일을 읽고 결과를 선택 폴더 아래 `정제`, `대시보드` 폴더에 다시 저장합니다.
